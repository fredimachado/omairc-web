Omairc is a keyboard-first IRC client that keeps several networks, channels, direct messages, and each network's Status view in one window. Start here if you are installing it for the first time or want to learn the main interface.

## Get started

1. [Install Omairc](/docs/getting-started/installation/) on Arch/Omarchy, Windows, or macOS.
2. [Create your first connection](/docs/getting-started/first-connection/) and join a channel.
3. Learn how to [move between networks and conversations](/docs/guides/navigation/).
4. Read the [messaging guide](/docs/guides/messaging/) for the composer, history, find, and member list.

:::tip[New to IRC?]
A **network** is an IRC server profile. A **conversation** is a channel, a direct message, or a network's Status view. Status contains connection and server messages rather than channel chat.
:::

## Everyday setup

Open **Connect** with `Ctrl+,` (`Cmd+,` on macOS) to add or edit networks. The same sheet contains three [preferences](/docs/guides/preferences/) for reopening direct messages, loading peer avatars, and opening conversations at their unread marker.

Press `Ctrl+/` in Omairc to see the shortcuts available in your installed version. On macOS, the shortcut sheet displays `Cmd` and `Option` in place of `Ctrl` and `Alt` where appropriate.

## What to expect

After a successful connection, the left sidebar shows the network and its conversations, the middle column shows the selected transcript and composer, and channels can show a member panel on the right. Omairc can restore recent local transcript lines after restart and request server or bouncer history when the network supports it; availability therefore varies by server.
